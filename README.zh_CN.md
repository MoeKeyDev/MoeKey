# MoeKey

MoeKey 是由 Flutter 制作的跨平台 misskey 客户端。

## 特性

MoeKey 是使用 Flutter 开发的跨平台 Misskey 客户端，界面风格延续原版 Misskey。

> 项目仍在开发中。以下清单依据当前源码中的页面、交互和接口调用整理，不代表所有服务器版本均已实机验证；发布版可能晚于源码进度。

### 已支持

- **账号管理**：多账号登录、切换和移除账号。
- **时间线**：首页、本地、社交（混合）、全局时间线，分页加载与实时更新。
- **搜索与发现**：帖子与用户搜索、发现页、热门内容和话题标签浏览。
- **帖子发布**：文字与附件、回复、引用转发、投票、内容警告（CW）、可见范围、指定接收者与仅本地发布。
- **帖子操作**：转发、表情回应、投票、复制与分享链接；编辑、删除以及删除后重新编辑自己的帖子。直接编辑需要服务器支持 `notes/update`。
- **帖子翻译**：连接的服务器提供翻译服务时可用。
- **用户与关注**：用户主页、帖子、媒体、回应、便签、关注与粉丝列表；关注、取消关注，以及关注请求的接受、拒绝、查看和撤回。
- **通知**：分组通知、提及、指定接收者帖子、未读数量和成就获得通知。
- **个人资料编辑**：头像、横幅、昵称、简介、位置、生日、语言、自定义资料字段及被关注时的消息。
- **网盘**：浏览文件和文件夹、本地上传、从 URL 上传、创建文件夹、重命名、删除、修改文件说明与敏感标记。
- **便签（Clips）**：创建、编辑、删除、收藏便签，以及添加和移除帖子。
- **媒体与公告**：图片预览与保存、视频播放，系统公告浏览与已读确认。

### 尚未支持或仍不完整

- 天线、频道、用户列表的专用浏览与管理页面。
- 用户小组件：当前显示未支持提示。
- 完整的 Misskey 设置：目前已实现个人资料与账号管理；隐私设置入口尚未接通。
- 成就列表与详情页面：已支持成就获得通知，尚无完整的成就浏览功能。
